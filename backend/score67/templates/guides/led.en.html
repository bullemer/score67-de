Build your own LED scoreboard: 64 × 32 LED panel with an ESP32 for Score67

With a ready-made LED panel, a plug-on ESP32 controller and a power supply you can build a scoreboard for Score67 without soldering. The 64 × 32 panel and score display have been tested with the hardware listed below.

Status: the LED board works in hardware tests; registration and live data have been tested with a development server. Wi-Fi setup through a hotspot is implemented but has not been field tested. There is no public installable beta yet: the production connection, phone hotspot and browser installation still need field tests. Automatic updates are not implemented in the device firmware.

Make sure the controller says “S3”. The older “Matrix Portal M4” has a different processor and does not fit this guide. A power cable for the panel's connector is usually included – check the package contents.

Assembly

  1. Plug on the controller: on the tested Waveshare panel, the Matrix Portal S3 goes on the right-hand socket when viewed from the back. The printed arrows were misleading on this panel; the other socket left it dark or showed noise. No ribbon cable or soldering is needed.
  2. Power the panel: connect the panel's power cable to the 5 V supply (red = +5 V, black = ground). The panel draws up to 20 W – do not power it through the controller's USB-C port, which is too weak for that.
  3. Connect the controller: USB-C to your computer (to install the firmware) and later to a USB power supply.
  4. Install the firmware: this currently requires a development build and a USB cable. A public beta download and browser flash page will follow field testing.
  5. Pair with Score67: on first start the board opens its own Wi-Fi. Enter the venue Wi-Fi there. The board then shows its own six-digit code; enter it in Score67 under Settings → Displays.
  6. Assign a scoreboard: in the same list choose which scoreboard the board shows – you can switch during the game. The board follows that scoreboard's current game automatically.

Firmware updates

The server can host beta and stable firmware, and the app already has a “Receive beta firmware” switch. The device firmware does not install those updates yet. Until this is tested, each new version requires USB again.

Safety

  • Use a certified 5 V power supply (CE) only; do not work on mains voltage yourself.
  • Mind the polarity: swapping +5 V and ground can destroy panel and controller.
  • The panel gets warm – keep it free-standing, do not cover it.

Going bigger

Only a single 64 × 32 panel has been tested so far. Larger displays made from multiple panels have not been tested.

For makers: the interface

The firmware uses Adafruit Protomatter for the panel. It registers with a device key stored on the board through POST /api/display/register and receives scores over an encrypted WebSocket connection. The board shows its own pairing code. Want to write your own firmware? Get in touch in the forum.
