Build guide · draft

Build your own LED scoreboard: 64 × 32 LED panel with an ESP32 for Score67

With a ready-made LED panel, a plug-on ESP32 controller and a power supply you can build a scoreboard that shows the Score67 score in half an hour – no soldering. The board connects to score67.de over Wi-Fi and follows whichever scoreboard you assign to it in the app.

Status: the parts list and assembly are ready. The Score67 firmware for the controller is in the works; once it is available you install it with one click in the browser. The server side on score67.de (pairing by code, live data, updates over Wi-Fi) is already running.

Make sure the controller says “S3”. The older “Matrix Portal M4” has a different processor and does not fit this guide. A power cable for the panel's connector is usually included – check the package contents.

Assembly

  1. Plug on the controller: the Matrix Portal S3 goes straight onto the input header (HUB75 “In”) on the back of the panel – the arrows on the board show the data direction, the controller sits at the start. No ribbon cable, no soldering. The solder jumper for address line “E” is only needed for 64 × 64 panels, not for 64 × 32.
  2. Power the panel: connect the panel's power cable to the 5 V supply (red = +5 V, black = ground). The panel draws up to 20 W – do not power it through the controller's USB-C port, which is too weak for that.
  3. Connect the controller: USB-C to your computer (to install the firmware) and later to a USB power supply.
  4. Install the firmware (once available): open the Score67 flash page in Chrome or Edge, pick the controller, done. This is needed only once – every later version comes over Wi-Fi (see below).
  5. Pair with Score67 (once available): on first start the board opens its own Wi-Fi. Connect with your phone, enter the venue Wi-Fi and the pairing code. You create the code in the Controller under Game settings → Displays → Connect display (valid for 10 minutes).
  6. Assign a scoreboard: in the same list choose which scoreboard the board shows – you can switch during the game. The board follows that scoreboard's current game automatically.

Updates over Wi-Fi (OTA)

After the first install over USB nobody needs to plug in a cable again: new firmware versions come over Wi-Fi straight from score67.de.

  • Automatic, but never during a game: the board installs an update only when no game is running – e.g. when no scoreboard is assigned or between two games. While the clock runs, it waits.
  • Verified: the firmware is downloaded encrypted (HTTPS) and only with the board's own credentials. Before installing, the board checks a checksum; if it does not match, the old version stays.
  • With a fallback: the controller has room for two versions. If the new one does not start cleanly or cannot reach score67.de, the board switches back to the previous version by itself after a few attempts.
  • Visible in the app: under Game settings → Displays each board shows its firmware version, a note when an update is waiting and the update status (“installed 0.2.0”).
  • Beta for testers: with the “Receive beta firmware” switch a board gets new versions while they are still being tested. Without it, only released versions arrive.

Updates use the same Wi-Fi as the display – a phone hotspot works too. An update is about 1–2 MB.

Safety

  • Use a certified 5 V power supply (CE) only; do not work on mains voltage yourself.
  • Mind the polarity: swapping +5 V and ground can destroy panel and controller.
  • The panel gets warm – keep it free-standing, do not cover it.

Going bigger

Several panels can be chained through the output header (HUB75 “Out”), e.g. two or four panels for a larger gym board (128 × 64 pixels). The Matrix Portal S3 has the power for it, and the firmware is meant to support it from the start. The power supply must deliver more accordingly (up to 4 A per panel).

For makers: the interface

The firmware uses the ESP32-HUB75-MatrixPanel-DMA library for the panel. It talks to Score67 in two ways: once POST /api/display/pair with the pairing code (returns a device token), then a WebSocket wss://score67.de/ws/display?token=… that sends the current game on every change – teams and short names, colours, points, period and clock (the board keeps the time running locally).
